Trees

  • A binary tree of height h has at most 2^(h+1) − 1 nodes.
  • Nodes with two children = leaves − 1.
  • Inorder of a BST is sorted.
  • Inorder plus preorder (or postorder) determines the tree; preorder plus postorder does not.

Heap indices

0-based: left = 2i+1, right = 2i+2, parent = ⌊(i−1)/2⌋

Address arithmetic

Row major: a[i][j] = base + ((i × cols) + j) × size

Column major: a[i][j] = base + ((j × rows) + i) × size

C traps

  • p + i advances by i × sizeof(*p) bytes.
  • An array argument decays to a pointer, so sizeof gives the pointer size.
  • Signed overflow is undefined; unsigned wraps.
  • Mixing signed and unsigned promotes to unsigned: −1 < 1u is false.
  • struct size includes padding; union size is its largest member.

Stack push-pop orderings for n items number C(n) = (2n)!/(n!(n+1)!): 5 for n = 3, 14 for n = 4.
