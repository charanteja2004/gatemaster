Automata

  • NFA and DFA accept the same languages; subset construction can cost 2ⁿ states.
  • Moore output length is n + 1, Mealy is n.
  • The pumping lemma disproves regularity; passing it proves nothing.

Decidability

  • L is recursive ⟺ L and its complement are both recursively enumerable.
  • The halting problem is recursively enumerable but not recursive.
  • Rice: every non-trivial property of the recognised language is undecidable.
