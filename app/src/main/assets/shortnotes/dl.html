Digital Logic: revision sheet

Number systems

  • 2's complement of n bits: −2ⁿ⁻¹ to 2ⁿ⁻¹ − 1, single zero.
  • 1's complement: −(2ⁿ⁻¹ − 1) to 2ⁿ⁻¹ − 1, two zeros.
  • Binary to Gray: g(i) = b(i+1) ⊕ b(i). Gray to binary: b(i) = b(i+1) ⊕ g(i).

Boolean identities

A + AB = A; A + A'B = A + B; (AB)' = A' + B'; (A+B)' = A'B'

Adders

Full adder: Sum = A ⊕ B ⊕ Cin, Cout = AB + Cin(A ⊕ B)

Ripple carry delay is O(n); carry look-ahead computes carries in constant gate delay per block using G = AB and P = A ⊕ B.

Combinational blocks

  • n select lines choose among 2ⁿ multiplexer inputs.
  • A 2ⁿ-to-1 mux implements any n-variable function directly.
  • A decoder has n inputs and 2ⁿ outputs; an encoder is the reverse.
  • Five 4-to-1 muxes build a 16-to-1.
