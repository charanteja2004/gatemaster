Power: SLR(1) ⊂ LALR(1) ⊂ CLR(1). Merging CLR states into LALR can add reduce-reduce conflicts but never shift-reduce ones.

Grammar preparation

Left recursion: A → Aα | β ⟹ A → βA', A' → αA' | ε

Left factoring: A → αβ | αγ ⟹ A → αA', A' → β | γ

Left recursion breaks top-down parsers only. LR parsers handle it; they cannot handle ambiguity.

Attributes

  • Synthesised: from children, evaluable bottom-up, fits LR.
  • Inherited: from parent or left siblings.
  • S-attributed ⊂ L-attributed; L-attributed is what one pass can evaluate.

Optimisation

Machine-independent: constant folding and propagation, common subexpression elimination, dead code, copy propagation, loop-invariant motion, strength reduction. Machine-dependent: register allocation, instruction scheduling, peephole.
