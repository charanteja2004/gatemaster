SJF is optimal for average waiting time. Round robin is best for response time. Both facts are asked directly.

Deadlock

  • Coffman: mutual exclusion, hold and wait, no preemption, circular wait — all four at once.
  • Banker's algorithm avoids by refusing any request that leaves an unsafe state.
  • Unsafe is not deadlocked; it is merely not provably safe.

Memory

EAT with TLB = h·(TLB + M) + (1 − h)·(TLB + 2M)

EAT with page faults = (1 − p)·M + p·fault service time

  • Paging: no external fragmentation, internal up to one page.
  • Segmentation: no internal fragmentation, external instead.
  • Belady's anomaly: FIFO only. LRU and OPT are stack algorithms and immune.

Disk

Access time = seek + rotational latency + transfer

Average rotational latency is half a rotation: 4.17 ms at 7200 rpm.

Producer-consumer: take the counting semaphore before the mutex. The reverse order deadlocks, and it is the standard trick question.
