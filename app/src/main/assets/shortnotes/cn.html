Addressing

A /n prefix leaves 32 − n host bits, giving 2^(32−n) − 2 usable hosts

192.168.1.0/24 has 254 usable addresses; /26 subnets give 62 each.

  • Class A 1–126, B 128–191, C 192–223 by first octet.
  • Private ranges: 10/8, 172.16/12, 192.168/16.
  • The all-zero address is the network and the all-one is the broadcast, hence the −2.

Sliding window

Efficiency = W / (1 + 2a), where a = propagation time / transmission time

Stop and wait: W = 1. Go-Back-N: W = N. Selective repeat: W ≤ 2^(k−1) for k sequence bits

Error handling

  • Parity detects odd numbers of bit errors only.
  • CRC detects burst errors up to the degree of the generator polynomial.
  • Hamming distance d detects d − 1 errors and corrects ⌊(d−1)/2⌋.

Routing

  • Distance vector (RIP): Bellman-Ford, counts to infinity, split horizon helps.
  • Link state (OSPF): Dijkstra over a flooded topology map.
  • BGP: path vector, between autonomous systems.

CSMA/CD gives Ethernet its minimum frame size: a station must still be transmitting when the furthest collision returns, so frame time ≥ 2 × propagation delay.
