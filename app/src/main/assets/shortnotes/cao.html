Computer Organisation: revision sheet

Performance

CPU time = instruction count × CPI × clock period

Amdahl: speedup = 1 / ((1 − f) + f/s)

Pipelining

Cycles = k + (n − 1); speedup = n·k/(k + n − 1) → k

Clock period = slowest stage + latch delay

  • Structural hazard: a resource clash.
  • Data hazard: RAW is true; WAR and WAW vanish with renaming.
  • Control hazard: an unresolved branch.
  • Forwarding removes most RAW stalls but not load-use.

Cache

Address = tag | index | offset

offset bits = log₂(block size); index bits = log₂(number of sets)

Average access = h·tc + (1 − h)·tm (simultaneous)

Average access = tc + (1 − h)·tm (hierarchical)

Addressing modes

Memory accesses for the operand: immediate and register 0, direct and register indirect 1, memory indirect 2.

Read whether the cache model is simultaneous or hierarchical. The same hit ratio gives different answers under each.
