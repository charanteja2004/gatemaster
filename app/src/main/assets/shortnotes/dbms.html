Keys

  • Super key: identifies uniquely. Candidate key: minimal super key. Primary: the chosen one.
  • X is a candidate key when X⁺ is every attribute and no proper subset is.

Normal forms

FormRemoves
1NFnon-atomic values
2NFpartial dependency on part of a key
3NFtransitive dependency on non-prime attributes
BCNFany determinant that is not a super key

3NF permits X → Y when Y is prime; BCNF does not. BCNF is always achievable losslessly but may lose dependency preservation.

Lossless binary decomposition ⟺ (R1 ∩ R2) → R1 or (R1 ∩ R2) → R2

SQL

Evaluation order is FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY. WHERE cannot see a SELECT alias; ORDER BY can.

NULL is unknown: x = NULL is never true, and NOT IN with any NULL returns no rows. Always use IS NULL.
