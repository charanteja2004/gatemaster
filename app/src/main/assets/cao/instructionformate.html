Instruction Formats

The instruction word is divided into an opcode field and operand fields. The split fixes how many operations and how many registers the machine can have.

bits for opcode + Σ bits per operand field ≤ instruction length

A 24-bit instruction with three register fields over 32 registers uses 3 × 5 = 15 bits, leaving 9 for the opcode, so at most 512 operations.

Expanding opcodes buy more instructions by spending operand bits: a rarely used instruction with fewer operands can take a longer opcode. Counting them is a standard question.

Fixed-length formats decode in one step and suit pipelining. Variable-length formats pack memory more tightly and complicate every fetch.
