The Instruction Cycle

  1. Fetch: MAR ← PC, read memory into MBR, PC ← PC + 1, IR ← MBR.
  2. Decode: work out the operation and the operand locations.
  3. Fetch operands, from registers or memory.
  4. Execute in the ALU.
  5. Write back, and check for interrupts.

The PC is incremented during fetch, before execution. A branch therefore overwrites an already-incremented PC, which is why relative displacements are measured from the next instruction.

Interrupts are checked at the end of an instruction, not in the middle, so the saved state is always a clean boundary.
