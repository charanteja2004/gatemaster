Machine Instructions

A machine instruction is the binary encoding the control unit decodes: an opcode plus operand fields.

AddressesInstruction looks likeOperands from
3ADD R1, R2, R3all named
2ADD R1, R2one is also the destination
1ADD R1accumulator implied
0ADDstack implied

Evaluating (A+B)×(C+D) takes 3 instructions on a three-address machine and 7 on a zero-address stack machine, but each stack instruction is far shorter.

Fewer addresses mean shorter instructions and more of them. Total program size can go either way, which is why the comparison must be computed rather than guessed.
