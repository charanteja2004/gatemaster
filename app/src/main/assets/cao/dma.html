Direct Memory Access

A DMA controller moves data between a device and memory over the bus, without the CPU handling each word.

  1. The CPU programs the controller with address, count and direction.
  2. The controller requests the bus and transfers.
  3. On completion it interrupts the CPU.

Transparentonly idle cyclesno slowdown, slowest transfer

Cycle stealing is the usual compromise. The CPU keeps running from cache while the controller takes occasional bus cycles it was not using anyway.

DMA writes bypass the cache, so a stale cache line can hide the new data. Cache coherence with DMA is handled by invalidating or by non-cacheable buffers.
