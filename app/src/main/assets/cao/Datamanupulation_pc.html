Data Transfer Instructions

Data transfer moves bits without changing them: register to register, memory to register, or through an I/O port.

  • LOAD brings a word from memory into a register; STORE sends it back.
  • MOVE copies between registers.
  • PUSH and POP transfer against the stack pointer, adjusting it automatically.
  • IN and OUT address I/O ports where I/O is not memory-mapped.

Transfer instructions do not set condition flags on most architectures. Testing a value after a MOVE therefore needs an explicit compare.
