Address = tag | index | block offset

index bits = log₂(number of sets); offset bits = log₂(block size)

32-bit address, 32-byte blocks, direct-mapped with 512 lines: 5 offset bits, 9 index bits, so the tag is 32 − 14 = 18 bits.

Increasing associativity cuts conflict misses and lengthens the hit path, because more tags must be compared in parallel.
