The Data Path

The data path is the collection of registers, buses, multiplexers and the ALU through which data actually moves; the control unit decides which of those paths is active each cycle.

  • Single-bus: cheapest, one transfer per cycle, so most instructions take many cycles.
  • Multiple-bus: several transfers per cycle, fewer cycles per instruction, more hardware.

Counting cycles for a micro-operation sequence is the standard exercise, and the bus count is what bounds how many of them can happen at once.
