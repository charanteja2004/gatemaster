Cache Memory and Locality

A cache is a small fast memory holding recently and nearby used blocks, exploiting temporal and spatial locality.

Average access time = h·tc + (1 − h)·tm (simultaneous access)

Average access time = tc + (1 − h)·tm (hierarchical access)

With tc = 10 ns, tm = 100 ns and h = 0.9, the simultaneous model gives 19 ns.

The three Cs

  • Compulsory: the first reference to a block. Larger blocks help.
  • Capacity: the working set exceeds the cache. A bigger cache helps.
  • Conflict: too many hot blocks share an index. More associativity helps.

Read the question for which model is meant. Simultaneous and hierarchical access give different numbers from the same hit ratio.

Write-through keeps memory always current and costs bandwidth; write-back defers and needs a dirty bit. Write-back plus write-allocate is the usual pairing.
