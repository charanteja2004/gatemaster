Structured Query Language

SQL is declarative: you describe the result you want, and the optimiser decides how to compute it.

SELECT dept, COUNT(*) AS n, AVG(salary) AS avg_pay
FROM employee
WHERE salary > 30000
GROUP BY dept
HAVING COUNT(*) > 5
ORDER BY avg_pay DESC;

Evaluation order is FROM, WHERE, GROUP BY, HAVING, SELECT, ORDER BY. That is why a column alias defined in SELECT cannot be used in WHERE but can be used in ORDER BY.

WHERE filters rows before grouping; HAVING filters groups after. An aggregate in WHERE is an error.
