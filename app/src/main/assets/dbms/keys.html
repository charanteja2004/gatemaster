Keys in the Relational Model

KeyMeans
Super keyany attribute set that uniquely identifies a row
Candidate keya minimal super key
Primary keythe chosen candidate key
Alternate keythe candidate keys not chosen
Foreign keyreferences a key in another relation
Composite keya key made of more than one attribute

Every candidate key is a super key; the reverse fails because super keys need not be minimal. Adding any attribute to a candidate key gives another super key.

A primary key may not be NULL. A foreign key may, and a NULL foreign key means 'no related row', not a violation.
