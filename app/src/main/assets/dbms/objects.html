Database Objects

ObjectIs
Tablestored rows
Viewa stored query, computed on use
Indexa structure making lookups fast
Triggercode run on an event
Sequencea generator of unique numbers

A view stores no data. A materialised view does, and therefore needs refreshing — the trade-off between staleness and query cost.

An index speeds reads and slows writes, because every insert, update and delete must maintain it too.
