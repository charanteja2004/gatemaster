Filtering Rows in SQL

WHERE restricts which rows reach the rest of the query.

OperatorMatches
BETWEEN a AND binclusive range
IN (…)any value in the list
LIKE 'A%'pattern: % any run, _ one character
IS NULLthe only correct NULL test

NULL is unknown, not a value. x = NULL is never true, not even when x is NULL — always use IS NULL. Likewise NOT IN with a NULL in the list returns no rows at all.

Three-valued logic: TRUE, FALSE and UNKNOWN. WHERE keeps only rows where the condition is TRUE, so UNKNOWN behaves like FALSE for filtering but not for NOT.
