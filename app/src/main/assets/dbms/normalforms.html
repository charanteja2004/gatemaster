Normal Forms

FormRequires
1NFatomic values, no repeating groups
2NF1NF and no partial dependency on part of a key
3NF2NF and no transitive dependency on non-prime attributes
BCNFevery determinant is a super key
4NFBCNF and no non-trivial multivalued dependency

3NF allows X → Y when Y is a prime attribute; BCNF does not. That single exception is the whole difference, and the reason BCNF may lose dependencies.

R(A,B,C) with AB → C and C → B is in 3NF because B is prime, but not in BCNF because C is not a super key.

2NF only matters when the key is composite. With a single-attribute key, 1NF implies 2NF.
