Three-Tier Architecture

A presentation tier, an application tier holding business logic, and a data tier. Clients never speak to the database directly.

  • Scales, because the middle tier can be replicated and can pool connections.
  • Secures, because the database is not exposed to clients.
  • Maintains, because a rule changes in one place.

The middle tier is what makes connection pooling possible, and pooling is what lets a few hundred database connections serve millions of users.
