Multilevel Queue Scheduling

Split the ready queue into several queues with different policies, for instance interactive jobs on round robin and batch jobs on FCFS.

In a plain multilevel queue a process never changes queue. Multilevel feedback queues let a process move down when it uses a whole quantum and up when it waits, which approximates SJF without knowing burst lengths.

Scheduling between the queues is itself a policy: fixed priority risks starving the lower queues, so time slices are often shared out instead.
