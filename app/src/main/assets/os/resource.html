Resource Allocation Graph

Processes and resources as nodes; a request edge points from a process to a resource, an assignment edge from a resource instance back to a process.

With one instance per resource type, a cycle means deadlock. With several instances, a cycle is necessary but not sufficient — the cycle may resolve when an instance is freed.

P1 → R1 → P2 → R2 → P1 with single instances is a deadlock. The same cycle with two instances of R2 may not be.
