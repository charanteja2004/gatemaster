Paging

Physical memory is divided into fixed-size frames and logical memory into pages of the same size. A page table maps one to the other, so a process need not be contiguous in physical memory.

Logical address = page number p + offset d; physical address = frame(p) × page size + d

With a 16-bit logical address and 4 KB pages, the low 12 bits are the offset and the high 4 bits index a 16-entry page table.

No external fragmentation, because every free frame is interchangeable. Internal fragmentation is at most one page, in the last page of the process.

The TLB

A plain page table costs two memory accesses per reference: one for the table, one for the data. A translation lookaside buffer caches recent translations.

Effective access time = h·(TLB + M) + (1 − h)·(TLB + 2M)

Multi-level page tables shrink the table but add a memory access per level, which makes the TLB hit ratio matter even more.
