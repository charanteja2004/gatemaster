Operating System Structure

StructureIdeaTrade-off
Monolithiceverything in one kernel address spacefast, hard to maintain
Layeredeach layer uses only the one belowclean, layer crossings cost
Microkernelminimal kernel, services in user spacerobust, more message passing
Modularloadable kernel modulesmonolithic speed, dynamic pieces

A microkernel keeps only scheduling, memory and IPC in the kernel. A driver crash then kills a user process rather than the machine, at the cost of extra context switches per request.

Linux is monolithic but modular: modules load into kernel space at run time, so a module bug still takes the kernel down.
