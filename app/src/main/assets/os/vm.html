Virtual Memory

Virtual memory runs a process whose logical address space is larger than physical memory, by keeping only the pages in use resident.

Demand paging brings a page in only when it is referenced. The first touch of each page costs a fault.

Effective access time = (1 − p)·memory access + p·page fault time

With 100 ns memory, an 8 ms fault service and p = 0.001, the effective access time is about 8100 ns — 81 times slower. Fault rates must be tiny to be tolerable.

Virtual memory also enables copy-on-write and shared libraries: two processes map the same frame until one writes, and only then is a copy made.
