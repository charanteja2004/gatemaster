Process Control Block

The PCB is the kernel's record of a process: everything needed to stop it and later resume it as if nothing happened.

  • Process id and state.
  • Program counter and CPU registers.
  • Scheduling information: priority, queue pointers.
  • Memory management data: page table or segment table pointers.
  • Accounting and I/O status, including open files.

A context switch is precisely the act of saving the CPU state into one PCB and loading it from another. The size of that state is what makes switching costly.
