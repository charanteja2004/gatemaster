The Readers-Writers Problem

Any number of readers may share the data, but a writer needs exclusive access.

The first solution lets a stream of overlapping readers keep a writer waiting forever, because the writer only gets in when the reader count reaches zero.

A read-write lock in a modern library is this problem solved once, usually in the fair variant.
