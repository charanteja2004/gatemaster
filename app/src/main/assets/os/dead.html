Deadlock

A set of processes is deadlocked when every process in the set waits for an event that only another process in the set can cause.

Coffman's four conditions

  1. Mutual exclusion: at least one resource is non-shareable.
  2. Hold and wait: a process holds one resource while requesting another.
  3. No preemption: a resource is released only voluntarily.
  4. Circular wait: a cycle of processes each waiting on the next.

All four must hold at once. Breaking any single one prevents deadlock, and every prevention scheme is exactly that: an attack on one condition.

Starvation is not deadlock. A starving process could run if the scheduler chose it; a deadlocked one could not run whatever the scheduler did.
