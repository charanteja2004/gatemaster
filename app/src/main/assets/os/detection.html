Deadlock Detection

Let deadlock happen, then find it by searching for a set of processes whose requests no available resources can satisfy.

  1. Start with Work = Available and mark processes with no allocation as finished.
  2. Find an unfinished process whose Request ≤ Work.
  3. Add its allocation to Work and mark it finished.
  4. Repeat; any process left unfinished is deadlocked.

O(m · n²) for n processes and m resource types

Detection has to be paired with recovery: kill a process, or roll one back and preempt its resources. Both lose work.
