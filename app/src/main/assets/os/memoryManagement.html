Memory Management

The memory manager decides where a process sits in physical memory and keeps processes out of each other's space.

  • First fit: first hole big enough — fastest.
  • Best fit: smallest adequate hole — leaves tiny unusable holes.
  • Worst fit: largest hole — generally worst in practice.

Base and limit registers give protection in hardware: every address is checked against the limit and offset by the base, so a process cannot name memory outside its own.
