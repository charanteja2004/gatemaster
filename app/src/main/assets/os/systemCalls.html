System Calls

A system call is a request from a user process for a service only the kernel may perform. It switches the CPU to kernel mode through a trap.

CategoryExamples
Process controlfork, exec, exit, wait
File managementopen, read, write, close
Device managementioctl, read, write
Informationgetpid, time
Communicationpipe, shmget, send, recv

fork returns twice: 0 in the child and the child's pid in the parent. A question asking how many processes a chain of n forks creates is asking for 2ⁿ.

A system call is not a function call. The mode switch, argument validation and possible scheduling make it orders of magnitude more expensive.
