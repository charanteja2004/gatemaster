Introduction to Compiler Design

A compiler translates a source program into an equivalent target program, reporting errors it finds along the way.

ToolDoes
Compilersource to target, ahead of execution
Interpreterexecutes the source directly
Assemblerassembly to machine code
Linkerjoins object files and resolves references
Loaderplaces the image in memory to run

The front end depends on the source language, the back end on the target machine. Splitting them at the intermediate representation is what lets n languages and m machines share n + m parts instead of needing n × m compilers.
