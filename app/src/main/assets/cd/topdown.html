Top-Down Parsers

Start at the start symbol and expand, predicting which production to use from the lookahead token.

  • Recursive descent: one function per non-terminal, possibly with backtracking.
  • Predictive (LL(1)): a parsing table indexed by non-terminal and lookahead, no backtracking.

Preparing a grammar

Left recursion: A → Aα | β becomes A → βA', A' → αA' | ε

Left factoring: A → αβ | αγ becomes A → αA', A' → β | γ

Is it LL(1)?

  • For A → α | β, FIRST(α) ∩ FIRST(β) must be empty.
  • If β can derive ε, FIRST(α) ∩ FOLLOW(A) must be empty.

Left recursion makes a recursive descent parser call itself with no input consumed — an infinite loop, not a wrong answer. Bottom-up parsers handle it without complaint.
