Error Detection and Recovery

A compiler should report the first error accurately and keep going, so one run finds many errors rather than one.

StrategyDoes
Panic modeskip tokens until a synchronising token such as ; or }
Phrase levelperform a local correction and continue
Error productionsadd rules for common mistakes to report them precisely
Global correctionfind the smallest edit making the input legal

Panic mode is the standard because it cannot loop and is trivial to implement. Global correction is optimal and too expensive to use.

Cascading errors are the real danger: one missing brace can produce dozens of meaningless messages after it, which is what synchronising tokens exist to stop.
