Basic Blocks and Flow Graphs

A basic block is a maximal run of instructions entered only at the first and left only at the last.

Finding the leaders

  1. The first instruction is a leader.
  2. Any target of a jump is a leader.
  3. Any instruction immediately after a jump is a leader.
  4. Each block runs from a leader to just before the next.

A flow graph has basic blocks as nodes and possible control transfers as edges.

Within a block every instruction executes exactly when the first does, which is what makes local optimisation safe with no analysis of the rest of the program.

A loop in the flow graph is found by a back edge to a dominator — the entry point of that loop.
