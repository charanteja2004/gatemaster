Ambiguous Grammars

A grammar is ambiguous if some string has two distinct parse trees, equivalently two distinct leftmost derivations.

E → E + E | E * E | id makes id + id * id parse two ways. Adding precedence levels — E → E + T, T → T * F, F → id — removes the ambiguity and encodes the precedence.

The dangling else is the other standard case: matching the else to the nearest unmatched if is a rule imposed on top of an ambiguous grammar.

Ambiguity of an arbitrary context-free grammar is undecidable, so no tool can flag it in general. Parser generators report conflicts, which are a symptom rather than a test.

Ambiguity belongs to the grammar. Some languages are inherently ambiguous, meaning no unambiguous grammar for them exists at all.
