S-attributed and L-attributed Definitions

  • S-attributed: only synthesised attributes. Evaluable in one bottom-up pass.
  • L-attributed: synthesised attributes, plus inherited ones that depend only on the parent and on siblings to the left. Evaluable in one left-to-right depth-first pass.

Every S-attributed definition is L-attributed; the reverse is false. L-attributed is exactly the class a one-pass compiler can evaluate while parsing.

An inherited attribute depending on a sibling to the right breaks the single pass, because that sibling has not been parsed yet.
