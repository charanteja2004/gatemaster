Asymptotic Notations

Asymptotic notation compares growth rates and throws away constants, because constants depend on the machine and growth does not.

NotationMeaningReads as
O(g)f ≤ c·g for large nat most, upper bound
Ω(g)f ≥ c·g for large nat least, lower bound
Θ(g)both of the aboveexactly this order
o(g)f/g → 0strictly smaller
ω(g)f/g → ∞strictly larger

f(n) = O(g(n)) ⟺ ∃ c > 0, n₀ such that 0 ≤ f(n) ≤ c·g(n) for all n ≥ n₀

3n² + 5n log n + 100 is Θ(n²). The n log n and constant terms are dominated, and the factor 3 is absorbed into c.

The order that matters

1 < log n < √n < n < n log n < n² < n³ < 2ⁿ < n!

O is an upper bound, not a promise of tightness. n is O(n²) is a true statement and a useless one, which is why questions asking for the tightest bound expect Θ.
