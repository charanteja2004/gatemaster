Searching Algorithms

Two searches matter for GATE, and the difference between them is whether the data is already ordered.

Linear searchBinary search
Needs sorted inputnoyes
Worst caseO(n)O(log n)
Best caseO(1)O(1)
Works on linked listsyesnot usefully

Binary search needs random access. On a linked list, reaching the middle already costs O(n), which destroys the advantage.

Sorting to enable binary search costs O(n log n), so it pays only when many searches follow. For a single lookup, linear search wins.
