Prim's Algorithm

Grow one tree from an arbitrary start vertex, repeatedly adding the cheapest edge that leaves the tree.

O(V²) with an adjacency matrix, O(E log V) with a binary heap

Prim keeps a single connected tree at every step, which is why it suits dense graphs: the matrix version needs no heap at all.

Works only on connected graphs. On a disconnected graph it finds the MST of the component it started in.
