Radix Sort

Sort by the least significant digit first, then the next, using a stable sort at each pass. After the last digit the array is fully ordered.

T(n) = Θ(d · (n + b)) for d digits in base b

The inner sort must be stable, otherwise the ordering achieved by earlier digits is destroyed. Counting sort is the usual choice.

Sorting 32-bit integers in base 2¹⁶ takes 2 passes of counting sort over 65 536 buckets: linear in n for any n worth sorting.

Radix sort is not a comparison sort, so the Ω(n log n) bound does not apply to it. It is not universally faster though — d and b hide real constants.
