Dijkstra's Algorithm

Single-source shortest paths on a graph with non-negative weights. Repeatedly settle the unvisited vertex with the smallest tentative distance and relax its outgoing edges.

if d[u] + w(u,v) < d[v] then d[v] = d[u] + w(u,v)

O(V²) with an array, O((V + E) log V) with a binary heap

Dijkstra fails on negative edges. Once a vertex is settled it is never revisited, so a later negative edge that would have shortened its path is ignored. Use Bellman-Ford instead.

A settled vertex has its final distance. That claim is exactly what non-negative weights guarantee and what negative weights destroy.
