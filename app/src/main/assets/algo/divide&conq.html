Divide and Conquer

Split the problem into independent subproblems, solve them recursively, and combine. Merge sort, quick sort, binary search and Strassen's multiplication all follow this shape.

The master theorem

T(n) = a·T(n/b) + f(n), a ≥ 1, b > 1

CaseConditionResult
1f(n) = O(n^(log_b a − ε))T(n) = Θ(n^(log_b a))
2f(n) = Θ(n^(log_b a))T(n) = Θ(n^(log_b a) · log n)
3f(n) = Ω(n^(log_b a + ε)) and regularT(n) = Θ(f(n))

Merge sort has a = 2, b = 2, so n^(log₂2) = n and f(n) = Θ(n): case 2 gives Θ(n log n).

The master theorem does not cover every recurrence. T(n) = 2T(n/2) + n/log n falls in the gap between cases 1 and 2 and needs the recursion tree instead.
