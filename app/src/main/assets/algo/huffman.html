Huffman Coding

Build an optimal prefix code by repeatedly merging the two least frequent symbols into a subtree.

  1. Put every symbol in a min-heap keyed by frequency.
  2. Remove the two smallest, make them children of a new node with the summed frequency, and insert it back.
  3. Repeat until one tree remains; left and right edges label 0 and 1.

O(n log n) with a binary heap

The code is a prefix code, so no codeword is a prefix of another and decoding needs no separators. Frequent symbols end up nearer the root and so get shorter codes.

Frequencies a:5, b:9, c:12, d:13, e:16, f:45 merge as (5+9)=14, (12+13)=25, (14+16)=30, (25+30)=55, (55+45)=100, giving f a 1-bit code and a the longest.

The tree is not unique — ties can be broken either way — but the total encoded length is.
