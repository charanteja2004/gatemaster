Subset Sum Problem

Decide whether some subset of a set of positive integers adds up exactly to a target.

S[i][t] = S[i−1][t] OR S[i−1][t − a(i)]

Θ(n · T) by dynamic programming

NP-complete in general, and the special case of 0/1 knapsack where value equals weight. The DP table is pseudo-polynomial for the same reason.

The recursion without a table is Θ(2ⁿ): each element is either taken or not, and every branch is explored.
