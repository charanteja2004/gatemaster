Strassen's Matrix Multiplication

Multiplying two n × n matrices the obvious way costs Θ(n3). Strassen's algorithm (1969) gets it down to about Θ(n2.81) by trading one multiplication for several additions — the first algorithm to beat the cubic bound, and the reason Θ(n3) is not a lower bound for the problem.

The naive divide and conquer that does not help

Split each matrix into four n/2 × n/2 blocks:

A = | A11  A12 |     B = | B11  B12 |     C = | C11  C12 |
    | A21  A22 |         | B21  B22 |         | C21  C22 |

C11 = A11·B11 + A12·B21
C12 = A11·B12 + A12·B22
C21 = A21·B11 + A22·B21
C22 = A21·B12 + A22·B22

That is 8 multiplications of half-size matrices plus 4 additions, giving

T(n) = 8T(n/2) + Θ(n2)  ⇒  T(n) = Θ(n3)

By the master theorem, a = 8, b = 2, so nlog28 = n3 dominates the Θ(n2) work. No gain at all — the recursion has bought nothing.

Strassen's seven products

Strassen found a way to compute the same four blocks from only seven multiplications:

M1 = (A11 + A22) · (B11 + B22)
M2 = (A21 + A22) ·  B11
M3 =  A11        · (B12 - B22)
M4 =  A22        · (B21 - B11)
M5 = (A11 + A12) ·  B22
M6 = (A21 - A11) · (B11 + B12)
M7 = (A12 - A22) · (B21 + B22)

and then recombines them with additions only:

C11 = M1 + M4 - M5 + M7
C12 = M3 + M5
C21 = M2 + M4
C22 = M1 - M2 + M3 + M6

Expanding C11 is a good sanity check: M1 + M4 − M5 + M7 collapses term by term to A11·B11 + A12·B21, which is exactly what the block formula demands.

Complexity

T(n) = 7T(n/2) + Θ(n2)  ⇒  T(n) = Θ(nlog27) ≈ Θ(n2.8074)

Master theorem case 1: a = 7, b = 2, f(n) = Θ(n2), and nlog27 ≈ n2.807 grows faster than n2, so the recursion leaves dominate.

Additions rise from 4 to 18, but additions cost Θ(n2) while a multiplication costs a full recursive call — so removing one multiplication is worth a great many additions.

Why it is rarely used in practice

  • Large constant factor. The 18 additions and the temporary matrices mean the naive algorithm is faster until n reaches somewhere in the hundreds.
  • Numerical stability. The subtractions cause more floating-point error accumulation than the naive method, which matters in scientific computing.
  • Requires a power of two. Matrices are padded with zero rows and columns up to the next power of 2, which can nearly quadruple the work in the worst case.
  • Memory. Each level allocates temporaries for the sums and the seven products.
  • Cache behaviour. Blocked iterative multiplication uses the cache extremely well; Strassen's scattered temporaries do not.

Beyond Strassen

The exponent has been pushed lower by later algorithms — Coppersmith–Winograd and its refinements reach roughly n2.37 — but their constants are so enormous that they are faster only for matrices far larger than any that exist. They are called galactic algorithms for that reason. The true lower bound for matrix multiplication is still open; only the trivial Ω(n2) is known, since every entry must be read.
