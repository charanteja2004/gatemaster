Binary Search

Halve the interval at every step: compare the middle element, discard the half that cannot contain the key.

int lo = 0, hi = n - 1;
while (lo <= hi) {
int mid = lo + (hi - lo) / 2;
if (a[mid] == key) return mid;
if (a[mid] < key) lo = mid + 1;
else hi = mid - 1;
}
return -1;

O(log n) worst and average, O(1) best

T(n) = T(n/2) + O(1) ⟹ T(n) = Θ(log n)

Writing mid = (lo + hi) / 2 overflows for large indices. lo + (hi - lo) / 2 is the same value without the overflow.

The number of comparisons in the worst case is ⌊log₂ n⌋ + 1. A search tree drawn over the recursion has that height, which is where the bound comes from.
