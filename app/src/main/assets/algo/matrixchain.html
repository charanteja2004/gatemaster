Matrix Chain Multiplication

Given dimensions of a chain of matrices, find the parenthesisation that minimises scalar multiplications. The product is the same; the cost is not.

m[i][j] = min over k of ( m[i][k] + m[k+1][j] + p(i−1)·p(k)·p(j) )

Θ(n³)

Θ(n²)

For A(10×100), B(100×5), C(5×50): (AB)C costs 5000 + 2500 = 7500, while A(BC) costs 25 000 + 50 000 = 75 000 — ten times worse for the same result.

The number of distinct parenthesisations is the Catalan number C(n−1), which is exponential. The Θ(n³) table is the whole point.
