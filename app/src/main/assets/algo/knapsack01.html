0/1 Knapsack

Each item is taken whole or left behind. Maximise value within a weight capacity.

V[i][w] = max( V[i−1][w], v(i) + V[i−1][w − w(i)] ) when w(i) ≤ w

Θ(n · W)

Θ(n·W) is pseudo-polynomial, not polynomial: W is a value, and writing it takes only log W bits. The problem is NP-hard, which this table does not contradict.

The greedy value/weight rule solves the fractional version optimally and the 0/1 version wrongly. That contrast is a standard exam question.
