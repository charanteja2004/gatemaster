Insertion Sort

Grow a sorted prefix one element at a time, sliding each new element back to its place.

for (i = 1; i < n; i++) {
key = a[i];
j = i - 1;
while (j >= 0 && a[j] > key) { a[j+1] = a[j]; j--; }
a[j+1] = key;
}

O(n) best (already sorted), O(n²) average and worst

The running time is Θ(n + I) where I is the number of inversions, so insertion sort is genuinely fast on nearly sorted input. That is why library sorts fall back to it for small or almost-ordered runs.

Stable, in place, and online: it can sort a stream as elements arrive, which none of the O(n log n) sorts can.
