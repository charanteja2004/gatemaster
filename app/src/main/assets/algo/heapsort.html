Heap Sort

Build a max-heap from the array, then repeatedly swap the root to the end and sift down over the shrinking heap.

  1. Build the heap bottom-up in O(n).
  2. Swap a[0] with the last unsorted element.
  3. Reduce the heap size by one and heapify the root in O(log n).
  4. Repeat n−1 times.

Θ(n log n) in all cases

O(1), sorted in place

Building the heap is O(n), not O(n log n). Most nodes are near the leaves and sift down only a level or two; the sum Σ n/2^h · h converges to O(n).

Not stable. Heap sort is the usual answer when the question demands O(n log n) worst case with O(1) extra space.
