Kruskal's Algorithm

Sort every edge by weight and add it if it joins two different components, using union-find to test that.

O(E log E), dominated by the sort

Kruskal builds a forest that only becomes a tree at the last step, so it handles disconnected graphs naturally, producing a minimum spanning forest.
