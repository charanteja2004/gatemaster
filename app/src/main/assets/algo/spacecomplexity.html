Space Complexity

Space complexity is the total memory an algorithm needs; auxiliary space is what it needs beyond the input.

AlgorithmAuxiliary space
Merge sortO(n)
Quick sortO(log n) average, O(n) worst
Heap sortO(1)
Counting sortO(n + k)
Recursive DFSO(V) for the stack

Questions usually mean auxiliary space. An in-place sort still occupies the input array, so quoting O(n) for heap sort is the common mistake.

Recursion is not free. Every unreturned frame occupies stack, which is why the worst-case depth of quick sort matters as much as its time.
