Bubble Sort

Repeatedly sweep the array swapping adjacent elements that are out of order. After pass i, the largest i elements are in place.

for (i = 0; i < n - 1; i++) {
swapped = 0;
for (j = 0; j < n - 1 - i; j++)
if (a[j] > a[j+1]) { swap(a[j], a[j+1]); swapped = 1; }
if (!swapped) break;
}

O(n²) worst and average, O(n) best with the swapped flag

Without the early-exit flag the best case is also O(n²). Questions often hinge on whether the optimised version is meant.

The number of swaps equals the number of inversions in the input, which is why bubble sort is sometimes used to count them.
