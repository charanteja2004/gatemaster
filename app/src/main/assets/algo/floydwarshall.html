Floyd-Warshall Algorithm

All-pairs shortest paths by dynamic programming: allow one more intermediate vertex at each stage.

d[i][j] = min(d[i][j], d[i][k] + d[k][j]) for k = 1…n

Θ(V³)

Θ(V²)

The k loop must be outermost. Swapping the loop order breaks the induction on which intermediate vertices are allowed, and quietly gives wrong answers.

Handles negative edges. A negative value on the diagonal after the run means a negative cycle passes through that vertex.
