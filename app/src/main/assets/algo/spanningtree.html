Spanning Trees

A spanning tree of a connected graph with n vertices is an acyclic connected subgraph containing all n vertices and exactly n−1 edges.

A minimum spanning tree is unique when all edge weights are distinct. Repeated weights can admit several MSTs of the same total weight.

  • Adding any non-tree edge creates exactly one cycle.
  • Removing any tree edge splits the tree into exactly two components.
  • A complete graph on n vertices has n^(n−2) spanning trees (Cayley's formula).

Cut property: the lightest edge crossing any cut belongs to some MST. Both Prim and Kruskal are that property applied in a different order.
