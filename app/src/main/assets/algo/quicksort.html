Quick Sort

Choose a pivot, partition the array so smaller elements sit left and larger sit right, then recurse on both sides. The pivot lands in its final position after partitioning.

CasePartitionRecurrenceTime
Besteven splitT(n) = 2T(n/2) + Θ(n)Θ(n log n)

Worst1 and n−1T(n) = T(n−1) + Θ(n)Θ(n²)

The worst case appears on already sorted input when the first or last element is the pivot — exactly the input people test with. Randomised or median-of-three pivots avoid it.

O(log n) average for the recursion stack, O(n) worst

Quick sort is not stable and is usually faster than merge sort in practice, because partitioning is a cache-friendly in-place scan.
