Gray Code

Gray code is an ordering of binary values in which consecutive values differ in exactly one bit.

DecimalBinaryGray
0000000
1001001
2010011
3011010
4100110

One bit changing at a time means a reading taken mid-transition is at worst off by one position, which is why shaft encoders use it. It is unweighted, so you cannot read its value positionally.

The rows and columns of a K-map are labelled in Gray code, which is exactly why adjacent cells differ in one variable and can be grouped.
