Floating Point Representation

value = (−1)^sign × 1.mantissa × 2^(exponent − bias)

Single (32-bit)Double (64-bit)
Sign11
Exponent811
Mantissa stored2352
Bias1271023

The leading 1 of a normalised number is implicit and not stored, so 23 stored bits give 24 bits of precision. Exponent fields of all 0s and all 1s are reserved for zero, denormals, infinity and NaN.

Floating point addition is not associative. (a + b) + c can differ from a + (b + c) because each rounding loses different bits.
