Multiplexers

A multiplexer selects one of 2ⁿ data inputs onto a single output, chosen by n select lines.

2-to-1: Y = S'·I0 + S·I1

A 2ⁿ-to-1 multiplexer implements any function of n variables directly: wire the truth table's output column to the data inputs and the variables to the selects.

With one extra inverter, a 2ⁿ⁻¹-to-1 multiplexer handles n variables: use n−1 as selects and feed 0, 1, the last variable or its complement to each data input.

Building a 16-to-1 from 4-to-1 multiplexers takes five: four in the first stage, one to select among their outputs.
