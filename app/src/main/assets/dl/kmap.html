Karnaugh Maps

A K-map lays the truth table out in Gray-code order so that logically adjacent minterms are physically adjacent and can be grouped.

  1. Fill the map from the truth table.
  2. Group 1s in blocks of 1, 2, 4, 8… as large as possible, wrapping around edges.
  3. Every 1 must be covered; groups may overlap.
  4. Read each group as the product of the variables that stay constant in it.

F(A,B,C,D) = Σm(0,2,8,10): A and C vary while B = 0 and D = 0, so the group of four reduces to B'D'.

Don't-care cells may be treated as 1 or 0, whichever makes the groups larger. Using them well is usually the difference between the intended answer and a longer one.

A prime implicant is a group that cannot be enlarged; an essential prime implicant is one covering a 1 that no other group covers. Essential ones must appear in the answer.
