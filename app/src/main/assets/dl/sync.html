Synchronous Sequential Circuits

All flip-flops share one clock, so the whole circuit moves between states at a single instant.

  1. Draw the state diagram and state table.
  2. Assign binary codes to states.
  3. Choose a flip-flop type and use its excitation table to find the input equations.
  4. Minimise those equations with K-maps.

JKJ and K, one may be don't-care

The JK excitation table has a don't-care in every row, which is why JK-based designs usually minimise to fewer gates than D-based ones.

The maximum clock frequency is set by the longest path: flip-flop propagation delay plus combinational delay plus setup time.
