Code Converters: Binary and Gray

Binary to Gray: g(n) = b(n), g(i) = b(i+1) ⊕ b(i)

Gray to binary: b(n) = g(n), b(i) = b(i+1) ⊕ g(i)

Binary 1010 → Gray 1111. Gray 1110 → binary 1011.

Binary to Gray is a parallel operation: every output bit depends on two adjacent input bits. Gray to binary is sequential, because each output feeds the next XOR — a chain, not a fan-out.
