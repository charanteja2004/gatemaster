Strings

A C string is a char array terminated by '\0'. The terminator is what every library function looks for, and it occupies a byte.

char s[] = "GATE" occupies 5 bytes; strlen(s) is 4 and sizeof(s) is 5.

strcpy and strcat do not check the destination size. Writing past the end is the classic buffer overflow, and it is undefined behaviour rather than a runtime error.
