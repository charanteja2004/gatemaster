Pointers

A pointer holds the address of an object. Dereferencing with * reads or writes the object at that address.

p + i advances by i × sizeof(*p) bytes, not by i bytes

For int *p pointing at address 1000 on a 4-byte-int machine, p + 3 is address 1012.

  • int *p — pointer to int.
  • int **p — pointer to pointer.
  • int (*p)[10] — pointer to an array of 10 ints.
  • int *p[10] — array of 10 pointers to int.

Read declarations from the identifier outwards, following precedence: [] and () bind tighter than *. That rule decides the last two lines above.

A dangling pointer refers to freed memory; a memory leak is allocated memory with no pointer left to it. Both are undefined behaviour territory and both are examined.
