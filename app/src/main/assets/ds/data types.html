Sizes are not fixed by the standard. Only the minimum ranges and sizeof(char) == 1 are guaranteed, which is why portable code uses stdint types.

Signed overflow is undefined behaviour in C; unsigned arithmetic wraps modulo 2ⁿ and is well defined. That difference is examined more often than the sizes.
