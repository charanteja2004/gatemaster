Depth-First Search

Follow one path as deep as possible, then backtrack. Recursive by nature, or explicit with a stack.

O(V + E) with an adjacency list

  • Cycle detection: a back edge to a vertex still on the recursion stack.
  • Topological sort: reverse of the finishing order in a DAG.
  • Strongly connected components: Kosaraju's two passes, or Tarjan's one.

In a directed graph, a cycle exists exactly when DFS finds a back edge. Reaching an already-visited vertex is not enough — it must still be on the current stack.
