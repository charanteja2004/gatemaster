Depth-First Search (DFS)

DFS follows one path as deep as it can go, then backtracks and tries the next unexplored branch. It uses a stack — usually the implicit call stack of a recursive function.

Algorithm

DFS(G):
    for each vertex u in V(G):
        colour[u] = WHITE
        parent[u] = NIL
    time = 0
    for each vertex u in V(G):
        if colour[u] == WHITE:
            DFS-VISIT(G, u)

DFS-VISIT(G, u):
    time = time + 1
    d[u] = time                 // discovery time
    colour[u] = GREY
    for each v adjacent to u:
        if colour[v] == WHITE:
            parent[v] = u
            DFS-VISIT(G, v)
    colour[u] = BLACK
    time = time + 1
    f[u] = time                 // finish time

The three colours matter: white is undiscovered, grey is discovered but not finished (it is on the current recursion stack), and black is finished. A vertex is grey exactly while it sits on the stack.

Adjacency listΘ(V + E)O(V) recursion stack

Edge classification

DFS on a directed graph classifies every edge (u, v) by the colour of v at the moment the edge is explored:

Colour of vEdge typeMeaning
WhiteTree edgev is discovered from u
GreyBack edgev is an ancestor of u — a cycle
Black, d[u] < d[v]Forward edgev is a descendant, already finished
Black, d[u] > d[v]Cross edgev is in another subtree

A directed graph has a cycle if and only if DFS finds a back edge. In an undirected graph only tree edges and back edges occur — forward and cross edges are impossible.

Parenthesis theorem

For any two vertices u and v, the intervals [d[u], f[u]] and [d[v], f[v]] are either completely disjoint, or one wholly contains the other. They never partially overlap. Containment means one vertex is a descendant of the other in the DFS forest.

Applications

  • Cycle detection — a back edge in directed graphs; in undirected graphs, an edge to a visited vertex that is not the immediate parent
  • Topological sort of a DAG — output vertices in decreasing finish time
  • Strongly connected components — Kosaraju's two passes, or Tarjan's single pass
  • Articulation points and bridges in undirected graphs, using discovery times and low-link values
  • Path finding, maze solving, flood fill

Common traps

  • DFS does not give shortest paths. Use BFS for unweighted graphs.
  • The traversal order depends on the order neighbours appear in the adjacency list, so one graph has many valid DFS orders.
  • Recursion depth is O(V), so a long path graph will overflow the call stack — an explicit stack avoids this.
