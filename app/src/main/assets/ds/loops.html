Counting iterations is the exam skill. for (i = 0; i < n; i++) runs n times; for (i = 1; i <= n; i *= 2) runs ⌊log₂ n⌋ + 1 times.

A nested loop where the inner bound is the outer index runs 0 + 1 + … + (n−1) = n(n−1)/2 times, which is Θ(n²) even though it looks half as costly.
