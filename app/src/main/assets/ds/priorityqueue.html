Priority Queue

A collection where the element removed is always the one with the highest priority, not the one that arrived first.

ImplementationInsertExtract best
Unsorted arrayO(1)O(n)
Sorted arrayO(n)O(1)
Binary heapO(log n)O(log n)

The heap is the usual answer because it balances both operations. Dijkstra, Prim and Huffman are all priority queues in a loop.
