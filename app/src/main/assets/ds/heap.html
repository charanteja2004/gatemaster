Heaps

A binary heap is a complete binary tree where every parent dominates its children — greater for a max-heap, smaller for a min-heap.

For index i (0-based): left = 2i+1, right = 2i+2, parent = ⌊(i−1)/2⌋

OperationCost
Find min or maxO(1)
InsertO(log n)
Extract rootO(log n)
Build from an arrayO(n)

Because the tree is complete it lives in an array with no pointers, and its height is always ⌊log₂ n⌋. A heap is not a search structure: finding an arbitrary value is still O(n).
