Circular Queue

Wrap the indices with modulo arithmetic so the free space at the front is reusable.

rear = (rear + 1) % size; front = (front + 1) % size

Full and empty both give front == rear. Either keep a count, or leave one slot unused and call it full when (rear + 1) % size == front — which is why a size-n circular queue often holds n−1 elements.
