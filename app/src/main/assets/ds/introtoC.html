Data Structures and Algorithms

A data structure is a way of organising data so that the operations you need are cheap. Which structure is right depends entirely on which operations dominate.

StructureAccessSearchInsertDelete
ArrayO(1)O(n)O(n)O(n)
Sorted arrayO(1)O(log n)O(n)O(n)
Linked listO(n)O(n)O(1)*O(1)*
BST (balanced)O(log n)O(log n)O(log n)O(log n)
Hash table—O(1) avgO(1) avgO(1) avg
HeapO(1) for min/maxO(n)O(log n)O(log n)

* Linked list insert and delete are O(1) only once you hold the node. Finding it first is O(n), which is where the confusion in exam options usually lives.
