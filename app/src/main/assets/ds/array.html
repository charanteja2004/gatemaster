Arrays

A contiguous block of equal-sized elements, so the address of any element is a constant-time calculation.

Address of a[i] = base + i × size

Row major: a[i][j] = base + ((i × cols) + j) × size

Column major: a[i][j] = base + ((j × rows) + i) × size

For int a[5][4] at base 2000 with 4-byte ints, a[2][3] in row-major order sits at 2000 + (2×4 + 3)×4 = 2044.

C stores arrays in row-major order. Questions that specify column-major are usually about Fortran or are testing whether you noticed.
