Breadth-First Search (BFS)

BFS explores a graph level by level: it visits every vertex at distance 1 from the source, then every vertex at distance 2, and so on. It uses a queue (FIFO), which is what makes the traversal breadth-first rather than depth-first.

Algorithm

BFS(G, s):
    for each vertex u in V(G):
        visited[u] = false
        dist[u]    = INFINITY
        parent[u]  = NIL

    visited[s] = true
    dist[s]    = 0
    Q = empty queue
    ENQUEUE(Q, s)

    while Q is not empty:
        u = DEQUEUE(Q)
        for each v adjacent to u:
            if not visited[v]:
                visited[v] = true
                dist[v]    = dist[u] + 1
                parent[v]  = u
                ENQUEUE(Q, v)

A vertex is marked visited when it is enqueued, not when it is dequeued. Marking on dequeue instead lets the same vertex enter the queue several times, which is a common source of wrong answers.

Complexity

RepresentationTimeSpace
Adjacency listΘ(V + E)Θ(V)
Adjacency matrixΘ(V2)Θ(V)

With an adjacency list every vertex is enqueued and dequeued once (Θ(V)) and every edge is examined once in a directed graph, twice in an undirected one (Θ(E)). With a matrix, finding the neighbours of a vertex costs Θ(V) regardless of how few there are, so the total is Θ(V2).

Why the distances are shortest paths

In an unweighted graph, dist[v] computed by BFS is the smallest number of edges from s to v. The queue holds vertices in non-decreasing order of distance, so a vertex is first reached along a shortest path.

This guarantee holds only when every edge has the same weight. For weighted graphs use Dijkstra's algorithm, or Bellman–Ford if negative weights are present.

The BFS tree and edge types

The parent pointers form a BFS tree rooted at s. In an undirected graph every non-tree edge is a cross edge, and it always joins vertices whose levels differ by at most 1. There are no forward or back edges — a frequent one-mark question.

Applications

  • Shortest path and minimum number of moves in an unweighted graph or grid
  • Connected components of an undirected graph
  • Testing whether a graph is bipartite: 2-colour by level, and an edge inside a level means an odd cycle, so the graph is not bipartite
  • Level-order traversal of a tree
  • Finding all vertices within k edges of a source
