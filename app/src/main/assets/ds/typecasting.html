Type Casting in C

Implicit conversion happens along the usual arithmetic conversions; explicit conversion is written with a cast.

char → short → int → unsigned → long → float → double

5 / 2 is 2 because both operands are int. 5 / 2.0 is 2.5 because the int is promoted to double before the division.

Mixing signed and unsigned promotes the signed operand to unsigned. −1 < 1u is false, because −1 becomes a very large unsigned value.
