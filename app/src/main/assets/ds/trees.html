Trees

A tree is a connected acyclic graph. A rooted tree with n nodes has exactly n−1 edges and one path between any two nodes.

  • A binary tree of height h has at most 2^(h+1) − 1 nodes.
  • A complete binary tree with n nodes has height ⌊log₂ n⌋.
  • In a binary tree, nodes with two children = leaves − 1.

Traversals

TraversalOrderYields for a BST
Inorderleft, root, rightsorted sequence
Preorderroot, left, rightuseful for copying
Postorderleft, right, rootuseful for deletion
Level orderbreadth firstneeds a queue

Inorder alone does not determine a tree. Inorder plus preorder, or inorder plus postorder, does — which is why reconstruction questions always supply inorder.

In a BST, search, insert and delete are O(h). That is O(log n) only while the tree stays balanced; inserting sorted data makes it a linked list with O(n) operations.
