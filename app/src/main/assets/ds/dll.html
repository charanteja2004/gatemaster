Doubly Linked List

Each node carries pointers both ways, so traversal and deletion work from either direction.

SinglyDoubly
Pointers per node12

The cost is one extra pointer per node and two pointer updates per operation instead of one. LRU caches use a doubly linked list precisely for the O(1) removal.
