Recursion

A recursive function solves a problem by calling itself on a smaller instance, with a base case that stops the descent.

Each call gets its own activation record holding parameters, locals and the return address. Space is therefore proportional to the maximum depth.

Towers of Hanoi: T(n) = 2T(n−1) + 1, giving 2ⁿ − 1 moves for n disks.

Tail recursion, where the recursive call is the last action, can be turned into a loop with no stack growth. C compilers may do this; the standard does not require it.

A missing or unreachable base case is not an infinite loop but a stack overflow: each call consumes memory that is never released.
