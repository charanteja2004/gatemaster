Functions

C passes every argument by value. Passing a pointer passes the address by value, which is what lets the callee modify the caller's object.

void swap(int *a, int *b) {
int t = *a; *a = *b; *b = t;
}
swap(&x, &y); /* works */
 
void bad(int a, int b) { int t = a; a = b; b = t; }
bad(x, y); /* does nothing */

An array argument decays to a pointer to its first element, so sizeof inside the function gives the pointer size, not the array size.

Activation records are pushed on the stack per call, which is why deep recursion overflows it.
