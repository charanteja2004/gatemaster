Singly Linked List

One pointer per node, traversal in one direction only.

struct node { int data; struct node *next; };
 
/* insert at front */
n->next = head;
head = n;
 
/* delete after p */
tmp = p->next;
p->next = tmp->next;
free(tmp);

Deleting a node needs its predecessor, which a singly linked list cannot reach from the node itself. That single limitation is the reason doubly linked lists exist.

Reversing a list needs three pointers — previous, current and next — because overwriting current->next loses the rest of the list.
